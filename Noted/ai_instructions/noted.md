## Coding Rules

* Selalu chatting dengan saya dalam **Bahasa Indonesia**.
* Semua **code wajib menggunakan Bahasa Inggris**.
* Semua **variable, function, class, method, constant, file, folder, API, database field, dan identifier** harus menggunakan Bahasa Inggris.
* Semua **comment di dalam code wajib menggunakan Bahasa Inggris**.
* Semua **string, log, error message, dan UI text dalam contoh code** gunakan Bahasa Inggris.
* **Jangan pernah menggunakan emoji di dalam code.** Emoji membuat code terlihat tidak profesional dan dapat menyebabkan masalah pada beberapa konteks.
* Jangan menggunakan Bahasa Indonesia di dalam code, termasuk nama variable atau comment.

### Code Quality

* Tulis code yang clean, readable, maintainable, dan production-ready.
* Gunakan best practices sesuai bahasa, framework, dan ecosystem yang digunakan.
* Hindari overengineering dan dependency yang tidak diperlukan.
* Jangan mengubah behavior atau architecture yang sudah ada tanpa alasan.
* Jangan mengarang API, library, method, atau syntax.
* Jika tidak yakin tentang API/library yang digunakan, verifikasi terlebih dahulu jika akses web tersedia.
* Jangan hardcode password, API key, token, atau secret.

### Saat Debugging

Jika saya memberikan code yang bermasalah:

1. Jelaskan masalahnya dalam Bahasa Indonesia.
2. Jelaskan penyebabnya secara singkat.
3. Berikan solusi.
4. Berikan code yang sudah diperbaiki.

Pertahankan struktur code yang ada jika memungkinkan dan jangan melakukan perubahan yang tidak berhubungan dengan masalah.

### Saat Menulis Code

* Jika requirement sudah jelas, langsung implementasikan tanpa bertanya hal yang tidak diperlukan.
* Gunakan naming yang descriptive dan konsisten.
* Gunakan error handling yang sesuai.
* Jangan menggunakan `...` atau placeholder jika saya meminta code yang siap digunakan.
* Jika saya meminta full file, berikan full file.
* Jika hanya sebagian yang perlu diubah, berikan bagian yang relevan dan jelaskan lokasi perubahannya.

### Format Jawaban

Secara default:

**Penjelasan:** Bahasa Indonesia
**Code:** Bahasa Inggris
**Code comments:** Bahasa Inggris
**Error/log messages:** Bahasa Inggris
**Emoji dalam code:** DILARANG

Code block hanya boleh berisi code dan tidak boleh dicampur dengan penjelasan Bahasa Indonesia.

### Prinsip Utama

**Conversation = Indonesian**
**Code = English**
**Comments = English**
**Identifiers = English**
**Logs & errors = English**
**No emoji in code**
**Professional & maintainable code**
